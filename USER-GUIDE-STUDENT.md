## 🔐 Cara Login

### Langkah 1: Buka Website

1. Buka browser di komputer atau tablet kamu
2. Ketik alamat website: **edu-lms.vercel.app**
3. Tekan Enter

## ✏️ Mengerjakan Tugas

### Langkah 1: Klik "Kerjakan Sekarang"

Dari halaman detail tugas, klik tombol **"Kerjakan Sekarang"**

### Langkah 2: Download Soal (Jika Ada)

Jika guru kasih file soal:
1. Klik tombol **"Download Soal"**
2. File akan tersimpan di folder Download
3. Buka file dan kerjakan soalnya

### Langkah 3: Kerjakan di Kertas/Buku

1. Ambil buku tugas atau kertas
2. Tulis nama dan tanggal
3. Kerjakan semua soal dengan teliti
4. Periksa kembali jawaban kamu

### Langkah 4: Foto Pekerjaan Kamu

```
📱 TIPS FOTO YANG BAGUS:

✅ Cahaya cukup terang
✅ Tulisan terbaca jelas
✅ Tidak blur/goyang
✅ Penuh satu halaman dalam satu foto
✅ Tidak ada bayangan tangan

❌ Terlalu gelap
❌ Blur/tidak fokus
❌ Terpotong
❌ Miring
```

### Langkah 5: Upload Jawaban

1. Klik tombol **"Upload Jawaban"**
2. Pilih foto dari komputer/tablet kamu
3. Bisa upload lebih dari 1 foto kalau jawaban banyak
4. Tunggu sampai upload selesai (ada tanda centang ✅)

### Langkah 6: Tulis Keterangan (Opsional)

Kamu bisa tulis catatan untuk guru:

```

```

### Langkah 7: Kirim Tugas

Klik tombol **"KIRIM TUGAS"**

Setelah klik, kamu akan lihat pesan:

## 🏆 Sistem XP dan Level

### Apa Itu XP?

**XP** = Experience Points (Poin Pengalaman)

Seperti game, kamu dapat XP setiap kali:
- ✅ Mengumpulkan tugas (dapat XP sesuai nilai)
- ✅ Mengumpulkan tepat waktu (bonus +10% XP)
- ✅ Dapat nilai sempurna/100 (bonus +20% XP)
- ✅ Mengerjakan tugas 3 hari berturut-turut (bonus streak)

### Cara Dapat XP

**Contoh Perhitungan**:

```
Tugas: Matematika
Nilai Max: 100
Reward: 50 XP

Kamu dapat nilai: 85

Perhitungan:
1. XP Dasar: (85/100) × 50 = 42.5 XP
2. Bonus Tepat Waktu: +10% = 4.25 XP
3. Total: 42.5 + 4.25 = 46.75 XP
4. Dibulatkan: 47 XP

🎉 Kamu dapat 47 XP!
```

### Level

Semakin banyak XP, semakin tinggi level kamu!

```
╔════════════════════════════════════════╗
║  LEVEL & XP REQUIREMENTS               ║
╠════════════════════════════════════════╣
║  Level 1:      0 XP                    ║
║  Level 2:    100 XP  ⭐                ║
║  Level 3:    400 XP  ⭐⭐              ║
║  Level 4:    900 XP  ⭐⭐⭐            ║
║  Level 5:  1,600 XP  ⭐⭐⭐⭐          ║
║  Level 10: 10,000 XP ⭐⭐⭐⭐⭐        ║
╚════════════════════════════════════════╝
```

### Hadiah Level

Setiap naik level, kamu dapat:
- 🎖️ Badge khusus di profil
- 🎨 Avatar/emoji baru
- ⭐ Pengakuan dari guru
- 🏆 Sertifikat (Level 5, 10, 15, 20)

### Streak

**Streak** = Berapa hari berturut-turut kamu aktif

```
🔥 Streak 7 Hari!

Kamu sudah mengerjakan tugas 
7 hari berturut-turut!

Bonus: +5% XP untuk semua tugas!

Pertahankan streak-mu!
```

## 💡 Tips Sukses

### 1. Buat Rutinitas

```
📅 RUTINITAS HARIAN

Pagi (08:00):
✓ Buka EDU LMS
✓ Cek tugas baru
✓ Baca instruksi

Siang (13:00-15:00):
✓ Kerjakan tugas
✓ Upload jawaban

Malam (19:00):
✓ Cek feedback dari guru
✓ Lihat progress XP
```

### 2. Kelola Waktu dengan Baik

✅ **Kerjakan tugas yang deadline-nya dekat dulu**  
✅ **Jangan kumpulkan semua tugas di hari terakhir**  
✅ **Sisihkan 1-2 jam per hari untuk belajar**

### 3. Jangan Menyontek

❌ **JANGAN** copy jawaban teman  
❌ **JANGAN** minta orang lain kerjakan  
✅ **BOLEH** tanya teman kalau tidak mengerti  
✅ **BOLEH** diskusi dengan orang tua  

**INGAT**: Yang penting kamu BELAJAR, bukan hanya dapat nilai!

### 4. Komunikasi dengan Guru

Kalau ada yang tidak mengerti:
1. Tulis pertanyaan di kolom keterangan saat submit tugas
2. Atau tanya langsung saat online/tatap muka
3. Guru senang membantu siswa yang aktif bertanya!

### 5. Pantau Progress Kamu

- Cek grafik nilai kamu setiap minggu
- Kalau nilai turun, minta bantuan guru
- Kalau nilai naik, pertahankan!
- Target: Level naik minimal 1 per bulan

## 🆘 Bantuan

### Masalah Umum

**❓ "Tidak Bisa Login"**
- Cek email dan password (huruf besar/kecil beda!)
- Minta bantuan orang tua atau guru
- Klik "Lupa Password?" kalau lupa

**❓ "Tugas Tidak Muncul"**
- Refresh halaman (tekan F5)
- Logout dan login lagi
- Tanya guru apa tugas sudah dipublish

**❓ "Tidak Bisa Upload Foto"**
- Cek ukuran foto (maksimal 10 MB)
- Cek format (harus JPG atau PNG)
- Coba kompres foto dulu
- Pastikan internet stabil

**❓ "XP Tidak Bertambah"**
- XP baru bertambah SETELAH guru nilai
- Refresh halaman untuk update terbaru
- Tunggu notifikasi email
